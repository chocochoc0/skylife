Skylife.js

A lightweight, zero-dependency JavaScript utility library for calculating atmospheric conditions, solar cycles, and dynamic time states.

Documentation GitHub Repository

Features

  • Zero Dependencies: Lightweight and fast vanilla JavaScript.
  • Solar Calculations: Precise sunrise, sunset, and daylight phase calculations based on coordinates.
  • Atmospheric States: Quick evaluation of simulated weather and sky conditions.
  • Modular Design: Import only what you need for your web apps or games.

Quick Start & Documentation

Install via script tag or include directly in your project:

<script src="https://skylife.js.org/skylife.min.js"></script>
<script>
  // Initialize Skylife utility
  const phase = Skylife.getSolarPhase(new Date(), { lat: 50.0, lon: 20.0 });
  console.log("Current Sky Phase:", phase);
</script>
